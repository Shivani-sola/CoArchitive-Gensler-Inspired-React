Each one replaces its placeholder automatically — no code change needed. The
placeholder is stacked underneath as a second CSS background layer, so a file
that is missing or misnamed simply shows the stock image instead of breaking.

Format: portrait crop, 3:4 aspect ratio (e.g. 900 x 1200), JPG, under ~300 KB.
Faces sit best slightly above centre. The grid renders them in greyscale and
restores full colour on hover, so avoid photos that are already desaturated.

To add a person: add them to DIRECTORS or TEAM in src/data.js using the
portrait() helper, then drop the matching file here.
